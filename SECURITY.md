# Security policy

## Supported versions

The latest published patch in the `1.x` release line is supported. Security fixes target the latest `1.x` patch; upgrade to that version when a fix is released. The crate's minimum supported Rust version is 1.75.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/frontal-labs/sdk-rust/security/advisories/new) or email [security@frontal.dev](mailto:security@frontal.dev). Please include the affected SDK version, Rust toolchain and operating system, reproduction steps, impact, and a proof of concept when possible.

Do not disclose a suspected vulnerability in a public issue or include API keys, credentials, or customer data in a report. The maintainers will coordinate a fix and disclosure with the reporter.
