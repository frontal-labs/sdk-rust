# Rust API contracts

The OpenAPI snapshots are shared Frontal API inputs. `sdk-endpoints.json` preserves the frozen endpoint inventory and must stay identical to [`references/typescript-sdk-endpoints.json`](./references/typescript-sdk-endpoints.json), copied from the TypeScript SDK at commit `8d0c43f5a1416255f0eaad0d828da774eb936f73`. It contains 370 routes across 17 services. This Rust SDK exposes 16 services and 367 routes; Sandbox remains in the reference inventory but is intentionally not part of the Rust API. The committed OpenAPI snapshots describe 186 active Rust routes directly, including the Workflows backend specification from Frontal commit `4d13dee59cba0fa73744a0fd8b64d009b30d7ad4`; the conformance report records the remaining OpenAPI gaps.

`cargo xtask contract` compares the frozen inventory with the TypeScript snapshot, checks each supported Rust service and route-level transport method, and verifies the exact set of active Rust routes absent from OpenAPI. `scripts/check_contracts.py` checks the TypeScript inventory match and OpenAPI snapshot hashes. `reports/conformance.json` and `reports/migration-matrix.md` describe this Rust repository only. Add concrete models when the contracts define their wire fields.
