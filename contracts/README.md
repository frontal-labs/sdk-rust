# Rust API contracts

The JSON and OpenAPI files here are shared Frontal API inputs for the Rust client. `sdk-endpoints.json` lists service operations and `coverage-floor.json` holds the project's coverage baseline. Do not edit generated snapshots by hand.

`reports/conformance.json` and `reports/migration-matrix.md` describe this Rust repository only. They currently report zero implemented operations because this repository contains a scaffold, not a runtime client. Regenerate the report from Rust source when operations are implemented.
