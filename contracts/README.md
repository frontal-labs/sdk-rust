# Rust API contracts

The OpenAPI snapshots are shared Frontal API inputs. `sdk-endpoints.json` must stay identical to [`references/typescript-sdk-endpoints.json`](./references/typescript-sdk-endpoints.json). The inventory retains the frozen TypeScript routes from commit `8d0c43f5a1416255f0eaad0d828da774eb936f73` and adds the Functions routes from `packages/functions` at commit `a82138eef859e6f0aed4f50f656cd0e015da8f58`. It contains 386 routes across 18 active service namespaces; this Rust SDK exposes 17 services and 383 routes, with Sandbox intentionally excluded. The committed OpenAPI snapshots describe 186 active Rust routes directly, including the Workflows backend specification from Frontal commit `4d13dee59cba0fa73744a0fd8b64d009b30d7ad4`; the conformance report records the remaining OpenAPI gaps.

`cargo xtask contract` compares the frozen inventory with the TypeScript snapshot, checks each supported Rust service and route-level transport method, and verifies the exact set of active Rust routes absent from OpenAPI. `scripts/check_contracts.py` checks the TypeScript inventory match and OpenAPI snapshot hashes. `reports/conformance.json` and `reports/migration-matrix.md` describe this Rust repository only. Add concrete models when the contracts define their wire fields.
