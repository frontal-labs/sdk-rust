# Rust API contracts

The OpenAPI snapshots are shared Frontal API inputs. `sdk-endpoints.json` is the Rust SDK route inventory and must stay identical to [`references/typescript-sdk-endpoints.json`](./references/typescript-sdk-endpoints.json), copied from the frozen TypeScript SDK at commit `8d0c43f5a1416255f0eaad0d828da774eb936f73`. The inventory includes 370 routes; the committed OpenAPI snapshots describe 151 of them directly. For the other 219 routes, the frozen TypeScript endpoint inventory is the authoritative route reference, and the report records that OpenAPI gap explicitly.

`cargo xtask contract` compares the Rust inventory with the frozen TypeScript snapshot, checks that all services and route-level transport methods are present, and verifies the exact set of OpenAPI-only gaps. `scripts/check_contracts.py` also checks the TypeScript inventory match and OpenAPI snapshot hashes. `reports/conformance.json` and `reports/migration-matrix.md` describe this Rust repository only. Add concrete models when the frozen reference or committed contracts define their wire fields.
